# Noaman Muhammad — portfolio v6

Upload every extracted file and folder to the root of your existing repository. Keep index.html beside assets/, illustrations/ and expertise/. Do not upload the ZIP or an enclosing folder.

In repository Settings → Pages use **Deploy from a branch → main → /(root)**. If already configured, commit the replacement files and wait for the Pages deployment to finish.

Read [GitHub-Update-Guide.md](GitHub-Update-Guide.md) for the complete walkthrough.

Version 6 includes eight full-colour scientific illustrations, the email nm@nuovofilm.com, and CV-based career and publication corrections. Illustrations are conceptual, not to scale or measured results.

For future edits use Noaman-Muhammad-Editable-Source-v6.zip, rebuild, and upload the new dist/client contents. No live website was changed while preparing this package.
